## Другие работы

[Объединение чеков и магазинов](Объединение%20чеков%20и%20магазинов.%20.ipynb) — подготовил выгрузку по двум магазинам. Связал чеки со справочником по `store_uuid`, проверил количество строк и сохранил результат в CSV и Excel. Для повторного запуска укажите путь к `store_checkout_queues.csv` и `store_stores.csv` в `DATA_DIR`. В итоговую выгрузку попадают чеки, для которых нашёлся магазин в справочнике.
