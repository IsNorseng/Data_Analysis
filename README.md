# Анализ данных на Python

Исследовательские кейсы для портфолио и пример подготовки табличной выгрузки. Материалы показывают очистку данных, объединение таблиц, расчёт показателей, визуализацию и проверку статистических гипотез.

## Тестовые задания

- [Продажи и товарные потери FMCG](test_tasks/x5-retail) - тестовое задание для X5 Retail Group. Готовый Excel-отчёт, сохранённые графики и выводы в Jupyter Notebook. Основные результаты видны на странице кейса.

## Состав репозитория

| Материал | Задача и содержание |
|---|---|
| [Рынок видеоигр](Games_market_analysis.ipynb) | Исследовать исторические продажи для планирования кампании на 2017 год: платформы, жанры, регионы, связь оценок с продажами и сравнение пользовательских рейтингов. |
| [Тарифы мобильного оператора](Tariff_analysis_professional.ipynb) | Сравнить Smart и Ultra: построить витрину «пользователь — месяц», рассчитать потребление и выручку, проверить различия между тарифами и регионами. |
| [Объявления о продаже квартир](Real_estate_market_research.py) | Подготовить данные Яндекс.Недвижимости: обработать пропуски, добавить признаки и изучить распределения площадей, цен, числа комнат и высоты потолков. |
| [Объединение чеков и магазинов](Объединение%20чеков%20и%20магазинов.%20.ipynb) | Объединить две выгрузки по `store_uuid`, привести типы, отобрать два магазина и сохранить результат в CSV и Excel. |

Первые три материала представлены как исследовательские кейсы, без заявления о внедрении или подтверждённом коммерческом эффекте. Подготовка чеков — отдельный пример прикладного скрипта; происхождение задания в репозитории не описано.

## Что реализовано

- **Видеоигры:** подготовка данных, анализ периода 2013–2016 годов, региональные профили спроса и t-тесты Уэлча. В ноутбуке сохранены графики и выводы.
- **Тарифы:** календарь активных месяцев, начисление абонентской платы и сверхлимитных услуг, сводные показатели, сравнение средних на уровне клиента и экспорт таблиц. Результаты выполнения в ноутбуке не сохранены.
- **Недвижимость:** предобработка, производные признаки и описательный анализ. Это экспорт из ноутбука, использующий `get_ipython()` и `display()`.
- **Чеки:** проверка обязательных полей, объединение `many_to_one`, контроль состава результата и выгрузка `store_queue_prepared.csv` / `store_queue_prepared.xlsx`.

## Данные и запуск

Исходные наборы данных для учебных проектов в репозиторий не включены. CSV тестового задания X5 Retail Group находится в `test_tasks/x5-retail/data/`. Ссылок на их скачивание нет; для повторного расчёта нужны исходные файлы из соответствующего задания или источника.

| Материал | Нужные файлы | Настройка пути |
|---|---|---|
| Видеоигры | `games.csv` | Список `DATA_CANDIDATES`; поддерживается файл рядом с ноутбуком. |
| Тарифы | `calls.csv`, `internet.csv`, `messages.csv`, `tariffs.csv`, `users.csv` | Переменная `DATA_DIR`. Обязательные поля перечислены в `REQUIRED_COLUMNS`. |
| Недвижимость | `real_estate_data.csv` с разделителем табуляции | Рядом со скриптом либо в `/datasets`. |
| Чеки | `store_checkout_queues.csv`, `store_stores.csv` | Переменная `DATA_DIR`. Упомянутый в коде контрольный Excel-файл в расчётах не используется. |

Для просмотра откройте файлы по ссылкам выше. Для расчётов нужны Python, Jupyter и библиотеки `pandas`, `numpy`, `matplotlib`, `seaborn`, `scipy`, `plotly`; для записи Excel — `openpyxl`. Точные версии окружения не зафиксированы.

1. Откройте нужный ноутбук в Jupyter, разместите данные и настройте путь.
2. Проверьте параметры вывода. Тарифный ноутбук при `SAVE_RESULTS = True` записывает таблицы и графики в `OUTPUT_DIR`; скрипт чеков сохраняет файлы в `DATA_DIR`.
3. Выполните ячейки по порядку. Файл исследования недвижимости рассчитан на IPython/Jupyter: обычный запуск через `python` потребует адаптации служебных вызовов.

## Ограничения

Без исходных данных повторное выполнение не проверено. Сохранённые результаты отражают прежние запуски. Выводы по играм относятся к историческому периоду; продажи и выручка сами по себе не измеряют прибыль, а наблюдаемые связи не доказывают причинность.

В исследовании недвижимости отмеченный чек-лист шире фактически представленного кода: ориентироваться следует на реализованные расчёты. В обработке чеков используется внутреннее соединение, поэтому записи без соответствующего магазина в результат не попадут.
