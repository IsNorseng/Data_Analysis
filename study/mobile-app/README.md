# Где покупатели уходят из мобильного приложения?

По журналу событий я восстановил путь от главного экрана до оплаты и проверил, повлияла ли смена шрифта на поведение покупателей. Для воронки учитывал порядок действий каждого пользователя. В эксперименте сравнил новый шрифт с двумя контрольными группами и учёл, сколько статистических проверок провёл.

Самая большая потеря оказалась на первом переходе. У 39,9% пользователей после главного экрана не наблюдалось перехода к предложениям. Подтвердить влияние нового шрифта на оплату по этим данным не удалось.
