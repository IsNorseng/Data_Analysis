# Анализ продаж в Excel

Тестовое задание на позицию экономиста-аналитика: подготовить отчёт о продажах за **ноябрь 2025 года** по **8 менеджерам и 27 брендам**.

[Скачать Excel-файл](%D0%A2%D0%B5%D1%81%D1%82.%20%D0%AD%D0%BA%D0%BE%D0%BD%D0%BE%D0%BC%D0%B8%D1%81%D1%82-%D0%B0%D0%BD%D0%B0%D0%BB%D0%B8%D1%82%D0%B8%D0%BA.%20%D0%90%D1%80%D1%82%D1%83%D1%80%20%D0%95.xlsx?raw=1)

- Подготовлена таблица «менеджер — бренд — выручка» на основе исходной выгрузки.
- Формулами рассчитаны продажи по менеджерам и брендам, премии, общие итоги и доли в выручке.
- Построены сводные таблицы и диаграммы структуры продаж по брендам.

| Показатель | Результат |
| --- | ---: |
| Общая выручка | 12 071 692,44 ₽ |
| Лидер среди менеджеров — Менеджер 5 | 2 945 515,32 ₽ (24,40%) |
| Лидер среди брендов — Бренд 17 | 3 572 854,20 ₽ (29,60%) |

Исходные данные, формулы, сводные таблицы и диаграммы находятся в одном файле. Менеджеры и бренды обозначены условными названиями.
