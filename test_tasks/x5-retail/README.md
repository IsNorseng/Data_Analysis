| Показатель | Результат |

| Выручка | 6,771 млрд ₽ |

- **Замороженные продукты** имеют максимальную долю потерь в штуках — **9,22%**. Стоимость потерь категории составляет **61,80 млн ₽**.

Потери выше 8% при выручке свыше 500 тыс. ₽ выявлены у **460 SKU из 500**. В этой группе **348 SKU класса A** формируют **401,37 млн ₽ потерь**, или **73,5%** всех потерь. Товар, пересекающий порог 80% или 95% накопленной выручки, включён в класс, который закрывает этот порог.

Из **40 020 исходных строк** удалены **20 точных дублей**, **100 строк без закупочной цены** и **50 строк с отрицательным количеством продаж**. В анализ вошли **39 850 строк**. Маржа и наценка рассчитаны как отношения сумм, потери в рублях оценены по закупочной цене.
