# Тестовое задание X5 Retail Group

Анализ продаж, маржинальности и товарных потерь в FMCG. Решение в Excel и Python.

Данные за IV квартал 2023 года. В исходном файле 40 020 строк, 500 товаров, 8 категорий и 100 магазинов.

## Материалы

| Файл | Что внутри |
| --- | --- |
| [Excel-отчёт](FMCG_Анализ_продаж.xlsx) | Итоги, расчёты по категориям и товарам, ABC, недельная и месячная сводки Power Query. |
| [Анализ продаж](notebooks/01_FMCG_Анализ_продаж.ipynb) | Очистка данных, расчёт показателей, ABC, графики и выводы. Все результаты сохранены в ячейках. |
| [Загрузка через Dask](notebooks/02_Dask_Загрузка_данных.ipynb) | Объединение CSV через Dask, российский формат чисел, обработка ошибок и код полной замены таблицы SQL Server. |
| [Исходные данные](data/sales_data.csv) | Исходные данные. |
| `results/` | Подробные выгрузки расчётов и сверка Power Query. |

## Как открыть ноутбуки

Скачайте репозиторий целиком и откройте папку `test_tasks/x5-retail`. В командной строке перейдите в папку проекта и выполните команды.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\jupyter lab
```

Откройте нужный файл из папки `notebooks`. Для повторного расчёта выберите **Kernel → Restart Kernel and Run All Cells**. Код, функции и пояснения находятся внутри ноутбуков. CSV ищется относительно папки проекта.

Во втором ноутбуке запуск записи в SQL Server управляется переменной `RUN_SQL`, которая по умолчанию равна `False`. Для загрузки потребуются подключение в `FMCG_SQL_ODBC` и установленный Microsoft ODBC Driver. Параметры и права описаны рядом с кодом.

## Как обновить Excel

Откройте **Данные → Запросы и подключения**, выберите параметр `pCsvPath` и укажите полный путь к `data/sales_data.csv`. Затем нажмите **Обновить всё**. Недельная и месячная таблицы находятся на листе «Динамика». Код запросов также сохранён в папке `power_query`.

## Принятые правила

- В Python удалены точные дубли и строки с отсутствующей ценой или отрицательным количеством. В Power Query отрицательные количества обнулены по условию задания. Разница показана на листе «Методика».
- Товар, которым пересекается граница 80% или 95% выручки, включается в класс ABC, закрывающий эту границу.
- При расчёте среднего недельного Turnover неделя относится к месяцу своего понедельника. Месячная выручка считается по дате операции.
- Расчёты Python и выполнение M-кода проверены. Обновление через интерфейс Excel и запись в действующий SQL Server требуют отдельной проверки.
